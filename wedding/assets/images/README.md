# Wedding photographs

Drop these files into this folder:

- `header.jpeg` — the full-width lake header.
- `thank you.jpeg` — the photograph on both thank-you screens.

The page automatically falls back to the illustrated placeholders until these files exist. For different filenames, update `photos` in `wedding/config.js`.

These are public GitHub Pages assets. Export web-sized copies without GPS metadata. Keep originals elsewhere.
